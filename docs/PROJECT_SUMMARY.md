## 🚀 Быстрый старт для проверки

### 1. Убедиться что сервер работает
```bash
# В одном терминале
php artisan serve
# или используется Valet/Docker/etc

# В другом терминале
npm run dev    # или npm run build
```

### 2. Открыть браузер
```
http://localhost/
```

### 3. Залогиниться как студент
```
Email: mckenna56@example.com
Password: password123
```

### 4. Перейти на тест
```
Menu → Каталог сервисов → Студентам → Оценка преподавателей
```

### 5. Заполнить анкету
```
1. Выбрать дисциплину
2. Заполнить 5 вопросов (выбрать оценку 1-5)
3. Заполнить текстовое поле
4. Нажать "Отправить"
```

### 6. Залогиниться как администратор
```
Использовать admin account из системы
```

### 7. Перейти на админ панель
```
Menu (левый сайдбар) → Анкетирование
или прямая ссылка: /admin/surveys-dashboard
```

### 8. Просмотреть результаты
```
- Обзор: графики
- Дисциплины: результаты
- Преподаватели: рейтинги
- Студенты: прогресс
```

## 📞 Поддержка

### Если возникла проблема

1. **Студент не видит дисциплины**
   - Проверить что студент принадлежит группе БПМ-20-1
   - Проверить что дисциплины привязаны к этой группе

2. **Админ не видит результаты**
   - Проверить что пользователь имеет роль admin или superadmin
   - Очистить кэш браузера

3. **Форма не отправляется**
   - Проверить консоль браузера на ошибки
   - Убедиться что все обязательные поля заполнены

4. **Графики не отображаются**
   - Проверить что data есть в БД
   - Обновить страницу
