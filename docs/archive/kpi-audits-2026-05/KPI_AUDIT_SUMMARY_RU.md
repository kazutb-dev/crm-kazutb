# 📋 КРАТКОЕ РЕЗЮМЕ АУДИТА КПИ

## НАЙДЕНО 7 КРИТИЧЕСКИХ ПРОБЛЕМ

### 1️⃣ **Нулевые K1-K5 в Таблице Live Aggregation** 🔴 КРИТИЧЕСКОЕ
- **Файл:** `KpiSummaryController.php`, метод `liveTeachersAggregation()`
- **Проблема:** Возвращает `k1: 0, k2: 0, k3: 0, k4: 0, k5: 0` для всех преподавателей
- **Причина:** Не агрегирует баллы по разделам (teaching, science, social, qualification, survey)
- **Следствие:** Невозможно увидеть распределение баллов
- **Исправление:** +200 строк PHP кода, переписать логику агрегации

### 2️⃣ **Неправильная Формула Рейтинга в Live** 🔴 КРИТИЧЕСКОЕ
- **Файл:** `KpiSummaryController.php`, строка 1256
- **Проблема:** `rank_score = total_points` (просто сумма), а не формула
- **Правильная формула:** `R = (K1+K2+K3+K4+K5) - НПУ`
- **Следствие:** Рейтинг не соответствует документации
- **Исправление:** Вызвать метод `teacherRankScore()` вместо простой суммы

### 3️⃣ **НПУ Не Применяется в Рейтинге** 🔴 КРИТИЧЕСКОЕ  
- **Файл:** `liveTeachersAggregation()` в `KpiSummaryController.php`
- **Проблема:** Вычисляется НПУ, но не вычитается из суммы K1-K5
- **Следствие:** Рейтинг не соответствует регламенту
- **Исправление:** Передать НПУ в `teacherRankScore()` при расчете

### 4️⃣ **Таблица Не Показывает K1-K5** 🔴 КРИТИЧЕСКОЕ
- **Файл:** `resources/js/Pages/Kpi/Summary.jsx`
- **Проблема:** Таблица показывает только ФИО и Рейтинг, без разбивки по K1-K5
- **Следствие:** Пользователь не видит откуда взялся рейтинг
- **Исправление:** Добавить колонки К1 (УМР), К2 (НИР), К3 (СВР), К4 (УПК), К5 (Опросы), НПУ

### 5️⃣ **Отсутствие Видимой Формулы Расчета** 🟠 ВЫСОКИЙ
- **Файл:** `resources/js/Pages/Kpi/SummaryTeacherCard.jsx`
- **Текущее:** Показывает статичный текст "R = (K1 + K2 + K3 + K4 + K5) - НПУ"
- **Нужно:** Показать конкретные числа "R = (0 + 0 + 0 + 0 + 0) - 600 = -600"
- **Исправление:** Создать компонент `FormulaBreakdown` с подстановкой переменных

### 6️⃣ **Казбекова Без Должности, НПУ=0** 🟠 ВЫСОКИЙ
- **Файл:** Таблица `users`
- **Проблема:** У Казбековой М.К. `position_title = NULL` → `НПУ = 0`
- **Следствие:** Рейтинг = 0 - 0 = 0 (неправильное)
- **Исправление:** Заполнить должность у всех преподавателей

### 7️⃣ **Рассчитанные vs Live Данные Несогласованны** 🟡 СРЕДНИЙ
- **Файл:** Две ветки кода в `KpiSummaryController`
- **Проблема:** KpiResult (правильные K1-K5) vs Live Aggregation (все нули)
- **Следствие:** Может быть разный результат в разных местах системы
- **Исправление:** Зафиксировать Live Aggregation, всегда использовать правильную логику

## 💬 КРАТКОЕ ОБЪЯСНЕНИЕ

**Проблема в одном предложении:**
Система показывает K1-K5 как нули вместо реальных значений и не применяет НПУ при расчете рейтинга.

**Почему это произошло:**
`liveTeachersAggregation()` - это fallback метод для случаев когда нет рассчитанных результатов в KpiResult таблице. Он не агрегирует баллы по разделам и не применяет формулу.

**Как это исправляется:**
Переписать логику агрегации чтобы:
1. Для каждого преподавателя найти все утвержденные KPI записи
2. Сгруппировать по разделам (teaching → K1, science → K2, etc)
3. Суммировать баллы по разделам
4. Применить формулу: R = (K1+K2+K3+K4+K5) - НПУ
