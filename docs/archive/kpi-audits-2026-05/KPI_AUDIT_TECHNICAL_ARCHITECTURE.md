## 🔄 Поток Вычисления Рейтинга (ДО и ПОСЛЕ)

### ТЕКУЩИЙ ПОТОК (НЕПРАВИЛЬНЫЙ):

```
kpi_entries (approved)
    │
    ├─ user_id: 123, section: 'science', points: 200
    ├─ user_id: 123, section: 'teaching', points: 150
    ├─ user_id: 124, section: 'science', points: 200
    └─ ...
    │
    ↓ liveTeachersAggregation() ❌ НЕПРАВИЛЬНО
    │
    ├─ total_points = 200 + 150 + 200 + ...
    ├─ k1 = 0  ❌ ОШИБКА: должно быть 150
    ├─ k2 = 0  ❌ ОШИБКА: должно быть 200 + 200
    ├─ k3 = 0  ❌ ОШИБКА: должно быть 0
    ├─ k4 = 0  ❌ ОШИБКА: должно быть 0
    ├─ k5 = 0  ❌ ОШИБКА: должно быть 0
    ├─ rank_score = 550  ❌ ОШИБКА: это просто сумма!
    └─ rank_score = 550 - 0 = 550  ❌ ОШИБКА: НПУ не вычтена!
    │
    ↓
    Таблица показывает: K1=0, K2=0, K3=0, K4=0, K5=0, Рейтинг=550
                        ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                        ВСЕ НУЛИ!
```

### ИСПРАВЛЕННЫЙ ПОТОК (ПРАВИЛЬНЫЙ):

```
kpi_entries (approved)
    │
    ├─ user_id: 123, section: 'science', points: 200
    ├─ user_id: 123, section: 'teaching', points: 150
    ├─ user_id: 124, section: 'science', points: 200
    └─ ...
    │
    ↓ НОВАЯ liveTeachersAggregation() ✓ ПРАВИЛЬНО
    │
    ├─ Группировать по user_id:
    │  ├─ user 123:
    │  │   ├─ section='teaching' → k1 = 150
    │  │   ├─ section='science' → k2 = 200
    │  │   ├─ section='social' → k3 = 0
    │  │   ├─ section='qualification' → k4 = 0
    │  │   └─ section='survey' → k5 = 0
    │  │
    │  └─ user 124:
    │      ├─ section='teaching' → k1 = 0
    │      ├─ section='science' → k2 = 200
    │      ├─ section='social' → k3 = 0
    │      ├─ section='qualification' → k4 = 0
    │      └─ section='survey' → k5 = 0
    │
    ├─ Вычислить рейтинг = (K1+K2+K3+K4+K5) - НПУ
    │  ├─ user 123: R = (150 + 200 + 0 + 0 + 0) - 600 = -250
    │  └─ user 124: R = (0 + 200 + 0 + 0 + 0) - 600 = -400
    │
    ↓
    Таблица показывает:
    ┌──────────────────────────────────────────────────────────┐
    │ ФИО | К1  | К2  | К3 | К4 | К5 | НПУ | Рейтинг        │
    ├──────────────────────────────────────────────────────────┤
    │ 123 | 150 | 200 | 0  | 0  | 0  | 600 | -250   ❌      │
    │ 124 | 0   | 200 | 0  | 0  | 0  | 600 | -400   ❌      │
    └──────────────────────────────────────────────────────────┘
    ^^^^^^^^^^^^^^^^^^^^^
    ВИДНЫ РЕАЛЬНЫЕ ЗНАЧЕНИЯ!
```

## 📊 Соответствие Регламенту

### Регламент (из документации 14.5):

```
┌─────────────────────────────────────────┐
│ Rппс = (К1+К2+К3+К4+К5) - К6             │
│ где К6 = НПУ (годовая нагрузка)          │
│                                          │
│ К1 = УМР (учебно-методическая работа)   │
│ К2 = НИР (научно-исследовательская)     │
│ К3 = СВР (социально-воспитательная)     │
│ К4 = УПК (учебно-профилактическая)      │
│ К5 = Опросы студентов                    │
└─────────────────────────────────────────┘
```

### Текущее Состояние (НЕПРАВИЛЬНОЕ):

```
Rппс = (0 + 0 + 0 + 0 + 0) - 0 = 0
       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
       Все нули! НПУ не применена!
```

### После Исправления (ПРАВИЛЬНОЕ):

```
Rппс = (150 + 200 + 0 + 0 + 0) - 600 = -250
       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
       Реальные значения! НПУ применена!
```
