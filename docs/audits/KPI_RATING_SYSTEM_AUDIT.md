## 🚨 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### 1️⃣ ПРОБЛЕМА: Нулевые K1-K5 в Live Aggregation (КРИТИЧЕСКАЯ)

**Файл:** `/app/Http/Controllers/KpiSummaryController.php` (строка 1256)  
**Метод:** `liveTeachersAggregation()`  

**Симптомы:**
- У преподавателя Казбековой Меруерт: `K1=0, K2=0, K3=0, K4=0, K5=0, Рейтинг=0`
- У других: `K1=0, K2=0, K3=0, K4=0, K5=0` при НПУ=600 → `Рейтинг = -600`
- В скриншотах таблица показывает колонки `План, Факт, Баллы, Статус`, но не показывает разбивку по K1-K5

**Корневая причина:**
```php
// ❌ НЕПРАВИЛЬНО: Всегда возвращает нули для K1-K6
return $rows->map(fn ($r) => [
    ...
    'k1' => 0.0,          // ← ВСЕГДА 0!
    'k2' => 0.0,          // ← ВСЕГДА 0!
    'k3' => 0.0,          // ← ВСЕГДА 0!
    'k4' => 0.0,          // ← ВСЕГДА 0!
    'k5' => 0.0,          // ← ВСЕГДА 0!
    'k6' => 0.0,          // ← ВСЕГДА 0!
    'rank_score' => (float) $r->total_points,  // ← Просто сумма, без формулы!
    'source' => 'live',   // ← Значит это fallback!
])->values()->all();
```

**Последствия:**
- ❌ Невозможно увидеть распределение баллов по разделам
- ❌ Рейтинг отображается неправильно (просто сумма вместо формулы)
- ❌ Несоответствие между KpiResult (где K1-K5 правильно) и Live данными

**Когда это используется:**
- Когда `KpiResult` для периода еще не создан
- Когда период активен и еще не закрыт
- Когда нужен preview данных до финального расчета

### 2️⃣ ПРОБЛЕМА: Несоответствие Формулы Рейтинга (КРИТИЧЕСКАЯ)

**В документации (14.5):**
```
Rппс = (К1+К2+К3+ К4 + К5) - К 6
```

**В коде (KpiCalculationService.php):**
```php
private function calculateRankScore(array $scores): float
{
    return $this->roundScore(
        $scores['k1'] + $scores['k2'] + $scores['k3'] + 
        $scores['k4'] + $scores['k5'] - $scores['k6']  // ✓ Правильно
    );
}
```

**В KpiSummaryController (teacherRankScore):**
```php
private function teacherRankScore(..., ?float $npuThreshold = null): float
{
    $npu = $npuThreshold ?? $k6;
    return ($k1 + $k2 + $k3 + $k4 + $k5) - $npu;  // ✓ Правильно
}
```

**Проблема в Live Aggregation:**
```php
// ❌ Это не соответствует формуле!
'rank_score' => (float) $r->total_points,
```

**Анализ скриншотов:**
- **Скриншот 1 (Summary):** Показывает 2025/2026 год, профессиональный рейтинг ППС
  - Казбекова: К1=0, К2=0, К3=0, К4=0, К5=0, Рейтинг=0 ← Правильно вычислено
  - Но НПУ не показывается в этой таблице (это ошибка UI)
  
- **Скриншот 2 (TeacherCard 777):** Показывает карточку преподавателя
  - K1=0, K2=0, K3=0, K4=0, K5=0, Рейтинг=0
  - Но есть запись "Публикации в журналах" с баллами = 200
  - Это должно быть в K2 (НИР), но отображается как 0!

### 4️⃣ ПРОБЛЕМА: Отсутствие НПУ в Отображении (КРИТИЧЕСКАЯ)

**В документации:**
- НПУ (выполнение годовой нагрузки) - критический показатель
- Профессор = 1000 баллов
- Ассоциированный профессор = 800
- Сеньор-лектор = 600
- Лектор = 500
- Ассистент = 400

**В коде (config/kpi.php):** ✓ Правильные значения

**В фронтенде (React):**
- `Summary.jsx` показывает `npu_threshold` и `rate` в объекте
- Но в таблице она не отображается четко!
- Нет вычисляемой формулы показывающей: R = (K1+K2+K3+K4+K5) - НПУ

**Скриншот 1 анализ:**
- Каржауова Элеонора: НПУ=600 (сеньор-лектор) ✓ Правильно определен
- Хамит Айтолкын: НПУ=600 ✓
- Казбекова Меруерт: НПУ=0, К5=0 ✗ НЕПРАВИЛЬНО! (должна быть должность?)
- Амангельдина Маржан: НПУ=600 ✓
- Сламқұл Индира: НПУ=400 (ассистент) ✓

**Проблема Казбековой:**
- У нее нет должности или НПУ не определена
- Формула: R = (0+0+0+0+0) - 0 = 0 ← НЕПРАВИЛЬНО!
- Должна быть: R = (K_реальные) - НПУ_установленное

### 5️⃣ ПРОБЛЕМА: Рассчитанные vs Live Данные (СРОК.НОСТЬ)

**Есть ДВА источника данных:**

1. **KpiResult (рассчитанные):**
   - Хранятся в таблице `kpi_results`
   - Создаются методом `KpiCalculationService::calculateForUser()`
   - Содержат правильные K1-K5 по разделам
   - Используются когда период закрыт/финализирован

2. **Live Aggregation (текущие):**
   - Агрегируются на лету из `kpi_entries`
   - Возвращают K1-K5 = 0 (ошибка!)
   - Используются как fallback когда нет KpiResult
   - Неправильный `rank_score` (просто сумма)

**Проблема:**
```php
// Из KpiSummaryController, teachersRanking()
if ($period) {
    $results = KpiResult::query()...  // ← Ищет рассчитанные результаты
    if ($results->isNotEmpty()) {
        return $results->map(...)  // ← Правильные K1-K5!
    }
}

// Fallback:
return $this->liveTeachersAggregation(...)  // ← Неправильные K1-K5 (все 0)!
```

**Когда это происходит:**
- ✓ Если период закрыт и результаты рассчитаны → OK
- ❌ Если период активен и нет KpiResult → Fallback возвращает неправильные данные

### Исправление #1: Правильная Live Aggregation (ВЫСОКИЙ ПРИОРИТЕТ)

**Файл:** `app/Http/Controllers/KpiSummaryController.php`  
**Метод:** `liveTeachersAggregation()` (строка ~1220)

**Что нужно сделать:**

```php
private function liveTeachersAggregation(...): array {
    // Шаг 1: Получить entries (как сейчас)
    $rows = KpiEntry::query()...->get();

    // Шаг 2: ДЛЯ КАЖДОГО USER агрегировать по РАЗДЕЛАМ
    $sectionScores = [];
    foreach ($rows as $row) {
        $userId = $row->user_id;
        if (!isset($sectionScores[$userId])) {
            $sectionScores[$userId] = [
                'k1' => 0, 'k2' => 0, 'k3' => 0, 'k4' => 0, 'k5' => 0
            ];
        }
        
        $section = $row->indicator?->section;  // teaching, science, social, etc
        $coefficient = self::SECTION_COEFFICIENT_MAP[$section] ?? null;
        if ($coefficient) {
            $sectionScores[$userId][$coefficient] += $row->points;
        }
    }

    // Шаг 3: Вернуть с правильными K1-K5 и формулой
    return $rows->map(fn ($r) => [
        'k1' => $sectionScores[$r->user_id]['k1'],
        'k2' => $sectionScores[$r->user_id]['k2'],
        'k3' => $sectionScores[$r->user_id]['k3'],
        'k4' => $sectionScores[$r->user_id]['k4'],
        'k5' => $sectionScores[$r->user_id]['k5'],
        'k6' => 0,  // K6 не используется
        'rank_score' => $this->teacherRankScore(
            $sectionScores[$r->user_id]['k1'],
            $sectionScores[$r->user_id]['k2'],
            $sectionScores[$r->user_id]['k3'],
            $sectionScores[$r->user_id]['k4'],
            $sectionScores[$r->user_id]['k5'],
            0,
            (float) $npu
        ),
        ...
    ]);
}
```
