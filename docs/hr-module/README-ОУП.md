# Приём на работу: шаблоны документов и справочник (инструкция для ОУП)

Модуль собирает три документа из одной записи о приёме: **трудовой договор**, **приказ о приёме** и
**личную карточку**. Каждый документ — это файл Word (.docx), в котором вместо данных стоят теги вида
`${fio}`. При формировании вместо тега подставляется значение, а условные блоки остаются или убираются
в зависимости от условий договора.

## Как заменить шаблон

1. В настройках модуля, раздел «Шаблоны», скачайте текущий шаблон нужного документа.
2. Откройте его в Word и измените текст или оформление как обычно. Теги оставьте как есть или
   перепечатайте целиком (правила ниже).
3. Сохраните файл как .docx и загрузите его в тот же раздел. Система проверит шаблон и покажет
   ошибки, если они есть: шаблон с ошибками не принимается.
4. Загруженный шаблон становится новой версией. Уже сформированные документы не меняются, у каждого
   записано, по какой версии шаблона он сделан. К прошлой версии можно вернуться там же.

Встроенные шаблоны всегда остаются версией 1.

## Правила для тегов

- Тег пишется латиницей: знак доллара, фигурные скобки и имя без пробелов, например `${salary}`.
- Не меняйте шрифт, цвет или выделение **внутри** тега. Word может разрезать такой тег на части, и он
  перестанет работать. Если система пишет, что тег не распознан, удалите его и напечатайте заново.
- Оформление тега (жирный, курсив, подчёркивание) переходит на подставленное значение. Жёлтый маркер
  с тегов снимается автоматически.
- Если данных нет, вместо значения печатается `__________`: документ можно скачать и неполным.
- Тег, которого нет в списках ниже, считается ошибкой.

## Условные блоки

Блок — это абзацы между тегами `${if_…}` и `${/if_…}`. Каждый из этих двух тегов должен стоять
**в отдельном абзаце**, без другого текста. В готовом документе абзацев с тегами блоков не будет.

```
${if_prob}
2.3. … испытательный срок продолжительностью ${prob_ru}.
- начало: ${start_ru} года.
${/if_prob}
```

- Блоки можно вкладывать друг в друга. Одно и то же имя блока можно использовать несколько раз,
  например в казахской и русской колонках.
- Начало и конец блока должны находиться в одной ячейке таблицы.
- В блок можно поместить целую таблицу.

| Блок | Когда остаётся |
|---|---|
| `${if_main}` … `${/if_main}` | Основная работа |
| `${if_sovm}` … `${/if_sovm}` | Совместительство |
| `${if_has_end}` … `${/if_has_end}` | У договора есть дата окончания (не бессрочный) |
| `${if_prob}` … `${/if_prob}` | Есть испытательный срок |
| `${if_week}` … `${/if_week}` | Пятидневная неделя (не сменный график) |
| `${if_sched_pps}` … `${/if_sched_pps}` | График ППС |
| `${if_sched_aup}` … `${/if_sched_aup}` | График АУП |
| `${if_sched_shift}` … `${/if_sched_shift}` | Сменный график |
| `${if_has_edu}` … `${/if_has_edu}` | Есть сведения об образовании |
| `${if_no_edu}` … `${/if_no_edu}` | Нет сведений об образовании |
| `${if_has_children}` … `${/if_has_children}` | Есть дети |
| `${if_no_children}` … `${/if_no_children}` | Нет детей |
| `${if_has_attachments}` … `${/if_has_attachments}` | Есть прикреплённые документы |
| `${if_no_attachments}` … `${/if_no_attachments}` | Нет прикреплённых документов |

## Строки таблиц и фото (личная карточка)

Строка таблицы, в которой стоит первый тег из списка, повторяется для каждой записи: для каждого
диплома, каждого ребёнка, каждого прикреплённого файла. Остальные теги ставятся в ту же строку.

| Таблица | Теги одной строки |
|---|---|
| Образование | `${edu_level}` `${edu_institution}` `${edu_year}` `${edu_specialty}` `${edu_diploma}` |
| Дети | `${child_name}` `${child_birth}` |
| Прикреплённые документы | `${att_no}` `${att_type}` `${att_name}` |

`${photo}` — место для фото 3×4: поставьте тег в отдельный абзац (удобно — в ячейку таблицы).
Если фото не загружено, там будет надпись «Фото 3×4».

## Справочник подразделений и должностей

Подразделения берутся из оргструктуры системы, должности — из справочника должностей. Для документов
у каждой записи хранятся падежные формы:

- подразделение: родительный падеж на русском («кафедры «Информационные технологии»») и форма на
  казахском («Ақпараттық технологиялар» кафедрасының»);
- должность: категория (ППС, АУП, УВП), родительный падеж на русском («старшего преподавателя») и
  притяжательная форма на казахском («аға оқытушысы»).

Русские формы при установке модуля заполнены автоматически, по правилам, и отмечены как
**«не проверено»**. Казахские формы, кроме должностей АУП и УВП, пока пустые: в документе на их месте
будет `__________`, а в списке недостающих полей появится строка «форма на казахском».
Формы проверяют и подтверждают сотрудники ОУП. Пока форма не подтверждена, у документа показывается
предупреждение.

Если нужного подразделения или должности нет, при оформлении приёма выберите «Ввести вручную»,
заполните формы и, если есть права, отметьте «Добавить в справочник».
