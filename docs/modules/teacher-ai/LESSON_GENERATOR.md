# AI-ассистент преподавателя: генерация лекции и презентации

Модуль `teacher-ai/lessons`. Преподаватель указывает дисциплину (название урока) и тему, при желании язык материалов
(ru / kk / en), аудиторию, длительность лекции, количество слайдов, номер лекции, факультет и кафедру для титульного
слайда, пожелания. ИИ в фоне готовит конспект лекции и презентацию в фирменном шаблоне КазУТБ с иллюстрациями.
Результат доступен в браузере и скачивается как DOCX (лекция) и PPTX (презентация).

Это черновик для преподавателя: ИИ может ошибаться, факты, формулы и список литературы нужно проверять. Решение о
содержании занятия всегда принимает человек.

## Доступ

Роли: `teacher`, `hod`, `dean`, `admin`, `superadmin` (как у проверки документов, см. `TeacherAiLessonController::ALLOWED_ROLES`).
Каждый преподаватель видит только свои материалы; чужие записи отдают 404.

Раздел сайдбара «AI-ассистент» содержит «Ассистент преподавателя» (этот модуль) и «Проверка документов».

## Как устроена генерация

Генерация выполняется очередью (`App\Jobs\GenerateTeacherAiLesson`) по шагам. Каждый шаг — отдельный запуск задания,
после шага задание ставит в очередь само себя. Это нужно, потому что cron-воркер запускается с `--timeout=120`
и один запуск задания не должен длиться дольше ~110 секунд.

| Шаг (`step`) | Запросов к ИИ | Что получаем |
|---|---|---|
| `outline` | 1 | название, цели, введение, план разделов, заключение, вопросы для самопроверки, глоссарий, литература, ключевые слова |
| `sections` | N параллельно (`Http::pool`, партиями по `TEACHER_AI_LESSON_CONCURRENCY`) | полный текст каждого раздела; шаг возобновляемый — генерируются только недостающие разделы |
| `slides` | 2 + число разделов, параллельно | части колоды: вступление (слайд-название лекции + обзорный слайд), по части на каждый раздел, заключение; шаг возобновляемый — повторяются только упавшие части |
| `images` | по `TEACHER_AI_IMAGE_CONCURRENCY` за запуск | иллюстрации для слайдов с картинкой (OpenAI Images); картинка, которую не удалось создать за 2 попытки, остаётся заглушкой и не роняет генерацию |
| `done` | — | статус `completed` |

### Шаблон презентации (версия 2)

Колода повторяет университетский шаблон: белые слайды, Times New Roman, круглый логотип КазУТБ в правом верхнем углу
каждого слайда, лавандовые карточки с индиго-акцентами, AI-иллюстрации. Первый слайд — титульный (университет,
факультет, кафедра, «Курс атауы:» / «Дисциплина:», город и год, фото главного корпуса), второй — название лекции
(«7-Дәріс. …» / «Лекция 7. …») с картинкой. Дальше чередуются 10 макетов: `text_bullets`, `timeline`,
`banner_columns`, `cards`, `image_text`, `chart`, `pyramid`, `stats`, `steps`, `hierarchy`; последний слайд — `conclusion`.

Формат JSON и геометрия макетов (холст 1280×720) общие для PPTX-экспорта и превью в браузере; контракт описан в
`App\Services\TeacherAi\LessonDeck` и в эталонной колоде `tests/Fixtures/TeacherAi/presentation-v2.json`.
Нормализация (`LessonDeckGenerator::normalizeSlide`) упрощает макет, если содержание не подходит (например, «этапы»
меньше трёх → карточки, диаграмма без чисел → карточки), поэтому рендереры всегда получают полные данные.

Диаграммы допускаются только для качественного сравнения технологий или методов по критериям (относительная шкала
0–100, как SRAM/DRAM в шаблоне): промпт запрещает страны, годы и статистику, чтобы ИИ не выдумывал данные.

Картинки хранятся на приватном диске `local` в `teacher-ai/lessons/{id}/`, отдаются только владельцу маршрутом
`teacher-ai.lessons.image` и удаляются вместе с материалом. Статические ресурсы шаблона: `public/assets/images/logo.png`
и `public/assets/teacher-ai/cover-photo.jpg` (собирается скриптом `scripts/teacher-ai/build-cover-photo.php` из
`public/assets/images/main.png`).

Статусы (`status`): `pending` → `processing` → `completed` | `failed`. Запись, которая «висит» в `pending/processing`
дольше `TeacherAiLesson::STALE_AFTER_MINUTES` (20 мин), показывается как ошибка и может быть перезапущена.

«Повторить» из интерфейса продолжает работу с того шага, на котором она остановилась: готовые план и разделы не
генерируются заново.

Классы:

- `App\Services\TeacherAi\TeacherAiChatClient` — HTTP-клиент к OpenAI-совместимому chat completions API (JSON-режим,
  один повтор при сетевой ошибке / 429 / 5xx / невалидном JSON / обрезанном ответе, пул параллельных запросов).
- `App\Services\TeacherAi\LessonGenerator` — промпты и нормализация ответов ИИ для каждого шага.
- `App\Services\TeacherAi\TeacherAiLessonService` — сценарий использования: лимиты, создание, выполнение шага,
  повтор, подготовка данных для Inertia.
- `App\Services\TeacherAi\LessonDocxExporter`, `LessonPptxExporter` — выгрузка в DOCX (phpoffice/phpword) и
  PPTX (phpoffice/phppresentation).
- `App\Services\TeacherAi\LessonLocale` — подписи заголовков в файлах на русском, казахском и английском.
- `App\Models\TeacherAiLesson`, таблица `teacher_ai_lessons`.

Ошибки с понятным текстом для преподавателя — `App\Services\TeacherAi\TeacherAiException` (от него же теперь
наследуется `TeacherAiReviewException`).

## Переменные окружения

Используются общие настройки модуля проверки документов (`TEACHER_AI_ENABLED`, `TEACHER_AI_ENDPOINT`,
`TEACHER_AI_MODEL`, `TEACHER_AI_API_KEY`; если ключ пуст — `OPENAI_API_KEY`) и дополнительные:

```env
TEACHER_AI_LESSON_DAILY_LIMIT=10     # генераций на преподавателя в сутки
TEACHER_AI_LESSON_TIMEOUT=90         # таймаут одного HTTP-запроса к ИИ, секунд
TEACHER_AI_LESSON_MODEL=             # модель для лекций; пусто — используется TEACHER_AI_MODEL
TEACHER_AI_LESSON_CONCURRENCY=4      # сколько разделов генерируется параллельно за один запуск задания
TEACHER_AI_LESSON_CITY=              # город на титульном слайде; пусто — «Астана»

TEACHER_AI_IMAGES_ENABLED=true       # иллюстрации к слайдам; false — колода без картинок (текстовые макеты)
TEACHER_AI_IMAGE_MODEL=gpt-image-1.5 # gpt-image-1.5 | gpt-image-2 | gpt-image-1 | dall-e-3
TEACHER_AI_IMAGE_QUALITY=low         # low | medium | high
TEACHER_AI_IMAGES_MAX=8              # максимум картинок на презентацию (включая слайд-название)
TEACHER_AI_IMAGE_CONCURRENCY=3       # картинок за один запуск задания
TEACHER_AI_IMAGE_TIMEOUT=90
```

При ответе 429 (лимит запросов к картинкам) следующий запуск задания откладывается на 30 секунд; такой ответ не
считается попыткой.

После изменения `.env` на сервере: `php artisan config:cache`.

Рекомендация по модели: `gpt-4o-mini` (по умолчанию) даёт ~1700 слов на 50-минутную лекцию за ~30 секунд;
`TEACHER_AI_LESSON_MODEL=gpt-4.1-mini` заметно подробнее (~3100 слов на 90 минут, корректный казахский) за ~60 секунд
и примерно в 2–3 раза дороже. Для reasoning-моделей (`gpt-5*`, `o3`, `o4-mini`) клиент сам убирает `temperature`,
передаёт `reasoning_effort: low` и `max_completion_tokens`; они медленнее, для этой задачи не обязательны.

## Время и стоимость

Обычно 2–5 минут на лекцию: 4 шага плюс паузы до минуты между запусками cron-воркера (сам расчёт ~1 минута).
Один материал на 15 слайдов — около 12–16 запросов к текстовой модели (~25 тыс. токенов `gpt-4o-mini`, ≈ $0.01)
и 4–6 картинок `gpt-image-1.5` low (≈ $0.01–0.02 за картинку, 8–12 секунд каждая).

## Данные и безопасность

- Во внешний сервис уходят только дисциплина, тема, аудитория и пожелания преподавателя. Интерфейс просит не
  указывать персональные данные.
- Тема и пожелания передаются модели как данные, системный промпт запрещает выполнять содержащиеся в них команды.
- Файлы DOCX/PPTX собираются во временной папке при каждом скачивании и удаляются после отправки.
- Сгенерированные картинки (JPEG ~150–250 КБ) хранятся в `storage/app/private/teacher-ai/lessons/{id}/` до удаления
  материала. При удалении пользователя строки удаляются каскадом, а папки картинок остаются — их можно удалить вручную.
- В промпт картинки уходит только описание сцены на английском, без персональных данных.

## Миграция и откат

Миграция `2026_10_20_000002_create_teacher_ai_lessons_table.php` только создаёт новую таблицу, существующие данные
не затрагивает.

Откат кода не требует отката БД: таблица просто перестанет использоваться. Если таблицу нужно удалить:

```bash
php artisan migrate:rollback --path=database/migrations/2026_10_20_000002_create_teacher_ai_lessons_table.php
```

Зависимости composer: `phpoffice/phppresentation ^1.2`, `phpoffice/phpword ^1.4` (ставятся `composer install` при релизе).

## Тесты

```bash
vendor/bin/phpunit --filter=TeacherAiLesson        # feature: контроллер, задание, резюмирование шагов, скачивание
vendor/bin/phpunit --filter=LessonGenerator        # unit: промпты и нормализация лекции
vendor/bin/phpunit --filter=LessonDeckGenerator    # unit: план колоды, макеты, сборка, картинки
vendor/bin/phpunit --filter=TeacherAiImageClient   # unit: клиент OpenAI Images
vendor/bin/phpunit --filter=TeacherAiChatClient    # unit: повторы и обработка ошибок клиента
vendor/bin/phpunit --filter=LessonExporters        # unit: валидность DOCX/PPTX
```

Feature-тестам нужна тестовая БД из `.env.testing` (`php artisan test` в production-окружении заблокирован
guard'ом, запускайте `vendor/bin/phpunit` из dev-копии).
