# CRM KazUTB

CRM система для сотрудников и студентов университета КазУТБ.

## Быстрый старт

1. git clone https://github.com/kazutb-dev/crm-kazutb.git
2. cd crm-kazutb
3. cp .env.example .env
4. composer install
5. npm install
6. php artisan key:generate
7. php artisan migrate
8. npm run dev
9. php artisan serve
