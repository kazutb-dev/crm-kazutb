# AGENTS.md — Политика и правила для агентов и командных инструментов

## Роли агентов
- Автоматизация рутинных задач (CI, тесты, деплой, документация)
- Проверка pull-requests, линтинг, автотесты
- Генерация boilerplate-кода, шаблонов, документации

## Workflow
- Все действия агентов логируются через PR/Issues
- Решения по архитектуре — только после ревью тимлида
- Вопросы — в Issues, тегать @aulykpan

## Pipeline
1. docs → 2. code → 3. review → 4. prod

## Push-policy
- Только через PR, без прямых пушей в main
- Каждый агент обязан обновлять документацию, если меняет workflow
